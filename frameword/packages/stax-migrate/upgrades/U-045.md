# U-045: the layout proof, or how a conversion argues with itself

TARGET: {{TARGET}}
REFERENCE: `stax-migrate proof`, `frameword/packages/stax-migrate/proof.mjs`

## DETECT

- The conversion has matrices and a running app, and nothing has ever put the
  two beside each other at the size the row declared. Ask for the artefact that
  does. If the answer is a status column, there is none.
- Grep the matrices for empty cells. If the count is zero on a first pass, they
  were not filled honestly: they were filled plausibly. A real first pass on a
  large product leaves hundreds of holes, and the holes are the work list.
- Cross-check the data matrix against the feature matrix: a `panel_binding`
  naming a panel no feature row declares is a contradiction nobody has read.

## APPLY

Run `stax-migrate proof` at phase 4 and again at phase 8, and hold the seven
disciplines it enforces:

1. Every render carries its row (file and line). No citation, not a panel.
2. The unknown is DRAWN, and its caption names what would settle it.
3. A disputed value is never silently picked: show both, count it.
4. A placeholder is dashed, so measured never looks like invented.
5. Every substitution is declared: what, what for, why.
6. The counts are published on the page.
7. The invariant is proven by repetition, once per manifest.

## VERIFY

- The unknown count at phase 8 is LOWER than at phase 4. Paste both numbers.
  A count that never falls is a conversion that learned nothing.
- Disagreements are zero at phase 8. At phase 4 a contradiction is a finding; at
  phase 8 it is one you shipped.
- Spot-check five rendered panels against the running app. A row claiming size L
  whose panel opens at M is the drift this artefact exists to catch.
- The file opens offline with no network request, in both themes.
